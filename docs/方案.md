# 北交摊位 4K 屏：一部像逛画展的七段短片

第二版，2026-09-23。第一版是电车串起九站的彩色剪纸片，被否决了：风格不统一、太儿童、电车撑不起主线。第一版已归档，见文末。

## 这部片要让路过的人停下来，看完知道摊位上卖什么、玩什么

27 寸 4K 屏在北京交通大学摊位上全屏循环，没有声音。9 月 27 日百校天则当天，路人一般只看几秒到几十秒。所以每一段都要能单独看懂：只看到一段的人，也知道那一段在卖什么或能玩什么。看完整轮的人，会觉得像看了一部有笑点的短片集。

摊位上有三类东西，片子都要讲到：

- **卖的：** 三眼的幻恋、隙间月影的名画微喷、会赢的亚克力挂件。
- **现场玩的：** 炼金工坊猜饮料、雏祭做人偶、二创红黑榜贴点。
- **发布的：** 北交东方笑话集。

## 片子照《图画展览会》编排：七幅互不相干的画，靠转场连起来

穆索尔斯基的《图画展览会》给十幅画各写一段音乐，每段性格不同，中间用「漫步」串起来。这部片照这个结构来：七件制品或活动各是一幅画，画法和节奏各不相同，不强行加共同的角色或道具。

- **转场代替漫步。** 画与画之间靠转场接上。有的是形状接形状，比如眼皮线变成隙间、魔药流成小溪、一个黑点变成贴纸；有的像参考视频那样，一格黑场直接切。
- **展签。** 每幅画开头，左上角出现一个白底黑框的字幕框，像美术馆的展签，写这幅画的名字或一句旁白。
- **大画框。** 整片外围一直有一圈手画的粗黑框，像画框。

| # | 画 | 时长 | 画法 | 怎么接到下一幅 |
|---|---|---|---|---|
| 1 | 三眼的幻恋 | 28s | 纯黑白木刻，黑多白少，只有一朵蔷薇是暗红；最后封面从水墨晕回彩色 | 紧闭的眼皮线变成一道隙间 |
| 2 | 隙间月影 | 22s | 编辑排版，暖白纸、黑字、一点暗紫 | 深色页暗成黑场 |
| 3 | 帕秋莉的炼金工坊 | 14s | 双色油印（灰青＋赭），纸面有细网点 | 剩下的魔药倒出来，流成一条小溪 |
| 4 | 雏 祭 | 18s | 手工说明书变成水墨河卷，红绿两色和纸 | 黑场 |

| 6 | 东方二创红黑榜 | 10s | 黑白木刻表格，小红点是唯一的颜色 | 黑场 |

## 七段用同一套颜色、笔触和字来统一

参考视频 `x_2102495989194236158.mp4` 定下了底子，七段都守下面五条。

- **颜色。** 低饱和。底色只用暖白纸 `#ebe5d8` 和近黑墨 `#161412`，外加几级灰。每段最多加一种压暗的颜色，雏祭按活动材料加红、绿两种；饱和度不超过 45%。第 1、5、7 段黑色面积大于白色。
- **笔触。** 墨块边缘粗糙，像木刻或刮画板。黑底上的细节用白色刮痕线画。线条每秒换 8 次形，就是手绘的「抖」；角色动作一拍两帧。
- **背景。** 背景有细节，但不抢主体。照 texture.fayaz.workers.dev 的 Paper、Linepress、Stipple 三种处理，只用细纸纹、极细横线和网点，明暗起伏不超过 5%。
- **字。** 屏上所有的字都用手写楷体（霞鹜文楷），包括价格、笑话正文和隙间月影的版面（用户 2026-09-23：「字体也应该和其他的一样好像手写的」）。叙述放在左上角的白底黑框字幕里，像参考视频的「day 0」。要读清的字把抖动调小，字号放大。
- **实拍素材。** 制品照片、封面、头像、实体表都按原样放，不调色、不涂鸦。它们是屏上唯一允许高饱和的东西，所以放得克制。

## 每一幅画在讲什么

**1 三眼的幻恋（已完成）。** 从桌面俯拍一个平面开场，照参考视频的开头来拍。

1. 钢笔滴下一滴墨，墨团平静成紧闭的觉之瞳，只有眼皮线和睫毛，伸出一根越长越乱的线。
2. 切进两侧都是书架的走廊，觉之瞳一路把书吸进去。
3. 黑底上两根藤蔓缠成心形，开出大朵白线蔷薇。一滴暗红落下，蔷薇变红又褪成灰。
4. 售卖信息两句：「三眼的幻恋作为包子的处女作」「在现场cos恋恋签售的就是作者」。
5. 字左移，右边三分之一露出封面水墨版，颜色从觉之瞳晕回彩色。
6. 一条紧闭的眼皮线拉成隙间，裂开。

前三个镜头的字幕是小说原句。除了封面不出现人物，不碰小说的关键情节。

**2 隙间月影（已完成）。** 隙间裂开后，是宣传册式的纸页。用户看过第一版后要求：分割线太多，字太多，字体要和其他段一样是手写的。返工后每幅只留四行：作品名、原作、角色和画师、规格和价格；去掉了台词、英文标签、页脚和分割线，全部换成手写楷体。

1. 开头一句「如果维米尔生活在幻想乡，他会画谁？」。
2. 四幅作品轮流出场：每幅先放原作名画，一道隙间横扫过去露出东方版，右栏逐行写出四行字。
3. 结尾深色页放 QQ 群二维码，四幅价格再列一次。

**3 帕秋莉的炼金工坊：一间只有一盏灯的魔药吧台。** 现场有同学 cos 帕秋莉当魔药师调饮料，片子就拍这个吧台。

1. 黑暗里一盏灯亮起，照出吧台。台后是魔药师的木刻剪影：月牙帽、长发、一本书。魔药师就是 cos 帕秋莉的同学「@」。
2. 架子上六瓶饮料，瓶身贴着角色贴纸和名字：阿求热带风味、赫卡可乐、慧音雪碧、天子水蜜桃、早苗绿茶、太田顺也啤酒。
3. 三瓶轮流跳下来倒进同一只烧瓶，倒的时候瓶身转过去，看不见是哪三瓶。
4. 包袱：太田顺也啤酒每次都往前挤，想被选上，每次都被推回去；最后一次终于被选上，一倒就冒泡溢出来。
5. 烧瓶推到观众面前，冒出一个问号烟，字幕「猜是来自哪些角色」。
6. 三个空格依次打钩，写「根据猜对数量决定奖励」，旁边出现奖品：一枚吧唧、一枚决策币。
7. 剩下的魔药倒出来，流过桌面，变成横贯画面的小溪线。

**4 雏 祭：一张手工说明书，最后展开成一条河。** 讲清楚来摊位能做什么：做一个雏人偶、写上祝福、摆上台领奖、放进河里流走。

1. 小溪线拉直成一把尺子，放在俯拍的手工桌上，和第 1 段的桌面呼应。材料一样样滑进来：红色和绿色和纸、白色卡纸、白乳胶、铁丝、彩笔、剪刀、胶带、马克笔。
2. 像说明书一样分三步做一个雏人偶，定格动画式地跳着做：
   - 剪刀剪出红色外衣、绿色内衬，叠起来。
   - 白卡纸做头，铁丝做支架。
   - 马克笔在衣服上写祝福语，写的是看不清的手写线，不编具体祝福的内容。
3. 字幕「把祝福语写在人偶上」。
4. 切到摊位上的阶梯陈列台，照摊宣引文里的雏坛。
   - 台上慢慢摆满各式各样的手作人偶，有剪的、画的、歪的，互不相同，这是笑点。
   - 最高一层是转台，上面坐着的键山雏玩偶在转圈，就是转转玩偶。玩偶照 TouhouLittleMaid 里 MC 键山雏的方块模型摆成坐姿，贴图压到低饱和。
   - 台边立着新版雏祭摊宣。
   - 一只手接过奖品，一枚吧唧、一枚决策币。
5. 镜头往下摇，陈列台变成河岸。人偶坐上小纸船顺水墨小溪漂走，三个装着头像的漂流瓶夹在中间一起漂。岸边一条红缎带打着转，把灰色的「厄」卷走。
6. 字幕用摊宣原话「留下想说的话 雏人偶会把厄运带走吧——」，小字可配用户给的流雏说明。

**5 会赢的。** 黑白漫画分格，默片节奏，讲「两者皆有可能……」和「这就是答案。」两句对白。亚克力挂件转一圈、停下，揭晓「没错，是博丽灵梦赢了！」。最后写「亚克力挂件 8元/套（包含两个单件）」。收尾时黑底白字的「赢」缩成一个黑点，交给第 6 段。

**6 东方二创红黑榜：一张被贴满点的表。** 开场接第 5 段的黑点。

1. 镜头拉远，黑点原来是一张黑点贴纸，贴在一张木刻风格画出来的表格上。表头「东方二创红黑榜」，下面是十二个作品名，图例写：
   - 红色：这种二创再来点！！
   - 黑色：创死我了！！
2. 四面八方伸进来很多只手，啪啪地贴小红点和小黑点，越贴越快。有的格子红点堆成山，有的格子红黑打架，这是笑点。
3. 最后亮出实体表的照片，字幕「用小红点和小黑点填表」「请和大家分享你对作品的喜欢吧！」。

**7 北交东方笑话集 发布：20 秒的 WASTED 淘汰赛。**

1. 四则笑话一则比一则好笑。新的一则进来，旧的那则就被盖上方框 WASTED 章淘汰。
2. 第四则停几秒，也被盖章。
3. 亮出最好笑的一则。
4. 古明地觉的第三只眼睁开，对着观众说「你刚才在脑袋里笑了」，落款「北京交通大学」。

盖章的手属于古明地恋，第四次盖章时才露出她的帽子。

每则只留铺垫的最后一句和包袱，原文逐字节选：

| 顺序 | 笑话 | 角色 |
|---|---|---|
| 1 | 萃香的戒酒打卡：第1天。第1天。第1天。 | 伊吹萃香 |
| 2 | 拼车评分 4.9，唯一差评「总觉得乘客越坐越多」 | 火焰猫燐 |
| 3 | 不灵不要钱：「你财运很差——刚刚又少了十块。」 | 博丽灵梦 |
| 4 | 「群友最想要的东西是npy。」「您无法选中不存在的目标。」 | 古明地觉、蕾米莉亚 |

- **灵梦：** 会赢的、第 3 则笑话。

## 取舍：每条都用 X 换 Y，按目的选了 X

- **三眼段最后才放封面，先水墨后彩色。** 用几秒片长换「一眼认出这本书」，同时让全片唯一一次满彩出现在售卖信息旁边。
- **三个活动段都拍「来了能做什么」，不讲故事。** 用叙事换路人看一段就知道怎么参与，因为活动的价值在现场参与。
- **雏祭用红绿两色，破了「每段一种颜色」。** 用画面统一换真实：现场材料就是红绿和纸，画成别的颜色，路人到摊位会对不上。两色都压到低饱和。
- **红黑榜的表格重画成木刻风格，最后才放实体照片。** 用「一开场就看到实物」换这一段和前后接得上。实体表是高饱和的彩色海报，放在开头会显得这一段不属于这部片。
- **笑话段压到 20 秒，每则只留铺垫的最后一句和包袱。** 用笑话的完整性换全片节奏，用户要求缩短。WASTED 格式本来就快，一则被盖章时下一则已经进来，两件事重叠着省时间。
- **隙间月影停 22 秒。** 用片长换四幅作品的价格都停够时间。价格是要被拍照带走的。
- **全片的字都换成手写楷体，价格和笑话也不例外。** 用印刷体的一点易读换全片统一，靠放大字号、调小抖动来保住易读。
- **WASTED 用开源字体 Anton 手作印章，不用 GTA 原版字体 Pricedown。** Pricedown 的许可不允许把字体文件放进网页，而展位的备用播放方式是网页。印章的方框、暗红和斜盖角度保留了 meme 的辨识度。
- **放弃游戏线。** 用互动性换一部片子的完成度。

## 第一版归档在 git 标签里，能直接用的部件已拆出来

- **第一版：** git 标签 `legacy/v1-tram-film`，内容是电车片九个镜头、剪纸画具、弹幕游戏。已从工作区删除，免得新施工照着旧风格做。取回用 `git show legacy/v1-tram-film:<路径>`。
- **第二版第一批的半成品：** 炼金工坊和雏祭的第一稿，当时 agent 被限流中断，存档在分支 `salvage/alchemy-v1`、`salvage/hina-v1`，联系表在 `out/salvage/`。能用的部件：
  - 炼金：烧瓶亮灯、倒液、问号烟、倒出来流成小溪。
  - 雏祭：水墨河、芦苇、装头像的漂流瓶、打转的红缎带。
- **原样沿用：** 引擎 `animation/engine/core.js`、抽帧和渲染工具 `animation/tools/`、素材打包脚本。
- **不再用：** 电车、Q 版剪纸小人、蜡笔纹理、白色撕纸毛边、彩色卡纸底。
