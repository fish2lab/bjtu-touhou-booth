# 北交摊位 4K 屏：一部手绘动画短片和一个弹幕小游戏

## 这块屏要让路过的人三秒内认出北京交通大学的东方摊位，并知道能来做什么

展位上一台 27 寸 4K 显示器全屏循环。看的人站在 1–3 米外，大多只瞥几秒。屏幕要做两件事：一眼认出「北京交通大学 · 东方」，再看到能参与的事——分享对作品的喜欢（红黑吧唧）、买「会赢的」挂件、给雏留言、猜帕秋莉的魔药、看隙间月影的名画微喷、加群。

两条线并行：动画是默认播放的内容；游戏是另一种形态，同样能无人值守地自己播，有人拿起键盘就能玩。

## 动画照着 kevin_t_ngo 的 Opus 5.5 短片做：每一帧由 JavaScript 画出，手绘小角色和真实物件互动

范本有三个，分工不同：

- 画风照 kevin_t_ngo（x.com/kevin_t_ngo）。他 9 月的几部短片都写明「Claude Opus 5 / 5.5 用 JavaScript 画出每一帧」：「What do you love?」是剪纸拼贴加蜡笔质感的绘本风，撕纸边带一圈白边，文字用圆润的手写体；9 月 17 日那部是 Claude 在搜来的图片上涂鸦。两者都有角色、有情节，不是幻灯片。
- 引擎照 hand-drawn-canvas-animation（MIT，github.com/IshaanKalra2103/creative-skills）。它按 kevin 的作品复刻了一套 Canvas 2D 短片引擎：固定种子的笔触、按帧曝光、照片上的涂鸦（`place`/`on`/`photo`/`pen`）、Web Audio 配乐、无头浏览器渲染 MP4。全部是经典脚本，照片以 data URL 内嵌，双击 `file://` 就能放。
- 隙间月影一段照 sukima-ml 的宣传册排版：暖白纸 #F7F6F4、墨色 #111、思源黑体 Medium 标题、等宽小字标签、细线和规格价格表，紫色 #4B2A63 只用于引言。

调研时没有找到同时满足「Opus 5.5 / Fable 5.1 生成」和「开源的手绘叙事短片」的仓库；kevin 只发视频不发源码，所以画风看他的成片，工程用上面那套 MIT 引擎。

## 故事用一辆手绘小电车串起所有素材，因为北京交通大学的梗就是「幻想乡交通大学」

主视觉里的恶搞校徽写着 GENSOKYO UNIVERSITY OF TRAFFIC。于是主角是一辆手绘小电车「幻想乡交通大学号」，驾驶员是校徽里正在焊东西的多多良小伞（撑着带眼睛和舌头的紫伞）。电车沿一条铅笔画出的轨道，从左往右开过摊位的每件真实素材，每件素材是一站；每站上来一位乘客，终点站所有人一起下车。电车是贯穿每个镜头的锚点，出画和入画方向一致，剪辑靠动作衔接。

## 游戏是东方式弹幕的自动演示，画面用同一套剪纸手绘，每张符卡对应一条摊位宣传

范本：riba2534/claude-opus-5-5-demo（单文件、程序化生成、没人操作时自动驾驶），以及 Sam1983Aing/domino-show（Opus 5.5，点一下后全自动运镜播完，最接近展位的无人值守场景）。

- 左侧是竖版弹幕场地，深蓝色卡纸夜空，子弹是带白色撕纸边的彩色剪纸（星、米粒、爱心、缎带、问号药瓶），白边保证在深色底上看得清。自机是小电车「幻想乡交通大学号」，Boss 是剪纸 Q 版八云紫。
- 右侧是宣传栏：当前符卡对应的宣传内容。北交摊宣三张卡沿用摊宣的黑白漫画版式；隙间月影那张用宣传册的编辑排版。
- 没人操作时 AI 自己躲弹（像东方的 replay）；按方向键、Z 或手柄就接管，15 秒没输入交还 AI。
- 符卡：红黑「二创红黑榜」、厄符「流し雛」、魔药「帕秋莉的炼金工坊」、境界「名画与东方的邂逅」，可选宣符「会赢的」。

## 这些取舍各自拿什么换什么

- 用真实素材当「被涂鸦的物件」，换掉全程序绘制的纯粹性。摊位要卖的就是这些东西，kevin 的涂鸦片也是这么做的。
- 隙间月影一段用宣传册的克制排版，放弃全片统一的涂鸦语气。名画微喷是商品，画面上不涂鸦，价格用印刷体写清楚。
- 现场播放预渲染的 4K MP4，放弃实时 HTML 的可改性。展位电脑性能未知，4K 下逐帧程序绘制可能掉帧；HTML 保留作源文件和备用。
- 游戏用剪纸画风，放弃东方原作的发光弹幕。好处是和动画一个世界；代价是子弹亮度靠白边和深底撑，需要截图验证可读性。
- 默认无声。展会现场嘈杂，配乐作为后续再做。

## 验收

- 动画：`animation/index.html` 双击能放，`?booth` 全屏自动循环；渲染出 `out/animation-4k.mp4`（3840×2160，24fps，约 90 秒），看全片联系表和关键动作的连续帧，没有空白帧、截断的动作、没写完的字。
- 游戏：`game/index.html` 双击能玩；每张符卡一张 4K 截图；10 分钟无人值守测试的死亡次数、最大同屏弹数；键盘接管与 15 秒交还测试通过。
