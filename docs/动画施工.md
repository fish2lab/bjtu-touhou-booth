所有脚本是经典脚本，共享一个全局作用域：**每个镜头文件里的顶层名字都要带本镜前缀**（如 `S3`、`s3Flyer`），否则会和别的镜头撞名，整部片打不开。需要新的画具就写在自己的文件里，不改 `kit.js`。

## 坐标、时间和衔接

- 逻辑画面 1920×1080（`W`、`H`、`CX`、`CY`），渲染时整体放大到 3840×2160。`fn(c, tau, i)`：`tau` 是本镜内的秒数，`i` 是 12fps 网格上的帧号（给 `pulse`、眨眼用）。
- 镜头和背景：先 `setView({ x, y, zoom })`，再 `paperBg(c, 颜色)`，之后画的东西都在镜头坐标里。
- 角色动作用 `twos(tau)` 取时间（一拍两帧，手绘感），镜头运动用连续的 `tau`。
- 衔接：每镜开头 0.45 秒镜头从左边甩进来，结尾 0.4 秒甩出到右边：`setView({ x: 中心x + whip(tau, dur, { inn: .45, out: .4, dist: 760 }), ... })`。电车永远从左往右开。第 8 镜进出隙间的方式自己定。
- 电车 `tram(c, x, 轨面y, s, o)`，远景 s≈90。车上的人按站累积：驾驶窗是小伞；第 3 镜起车窗 0 坐阿求，第 5 镜起车窗 1 坐雏，第 6 镜起车窗 2 坐帕秋莉。写法见 `s2-hearts.js` 里的 `driver` 和 `seats`。小伞坐在驾驶座时伞从车顶撑出来（`umbrella: {}`），下车后伞拿在手上。

## 画风规则（照 kevin_t_ngo「What do you love?」）

参考抽帧：`/Users/fish2lab/Project/BX/out/kevin/love-sheet.png`、`crops.png`，视频 `opus55-love.mp4`。

- 形状都是剪纸：`cut(c, 点, 颜色, { rim })` 画蜡笔质感的色块，外面一圈白色撕纸毛边和投影。黑线只用在五官、小动作线、电线这类细节上（`inkLine`）。不描黑边，不发光，不用渐变霓虹。
- 每站一张纯色卡纸底（`K.sky`、`K.mustard`、`K.mint`、`K.rose`、`K.lilac`、`K.navy`…），画面主体要大，别留大片空地。
- 真实素材当作「贴上去的印刷品」：`pasted(c, 名字, x, y, 高)` 带白边、投影和纸胶带；吧唧用 `badge()`。素材上可以有涂鸦互动，但不遮住素材上的字和人脸。
- 屏上文字用手写体 `zh(c, 字, x, y, { size, p })`，常写在 `notebook()` 横线纸上（马克笔蓝 `K.marker`），或直接写在卡纸上（`K.ink`）。主文案字号不小于 64（4K 上约 128 像素），停留不少于 1.5 秒。
- 角色：`kogasa`、`akyuu`、`hina`、`patchouli`，参数见 `kit.js` 里 `chibi` 的注释（`eyes`、`mouth`、`look`、`armL/armR`、`legs`、`sq`、`tilt`、`headOnly`）。跳跃用 `hop()`，站立起伏用 `idle()`。
- 装饰：`star`、`heart`、`dashes`（放射短线）、`grass`、`tape`、`strip`（撕纸地面）、`rails`。

## 验收命令

在仓库根目录（worktree 根目录）运行，退出码 0 且没有报错输出才算过：

```sh
node animation/tools/frames.mjs --q scene=<key> --grid 24 --cell 320      # 本镜联系表 → out/anim/
node animation/tools/frames.mjs --q scene=<key> --frames 30,90,150 --w 3840   # 本镜关键帧 4K 整帧
node animation/tools/frames.mjs --grid 36                                   # 全片能跑通
```

自己打开联系表和 4K 帧看：没有空白帧、没有截断的动作、字写完后停够时间、没有看不清的字、衔接方向对。
