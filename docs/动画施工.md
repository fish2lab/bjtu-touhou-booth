所有脚本是经典脚本，共享一个全局作用域：**每个段文件里的顶层名字都要带本段前缀**（如 `S2`、`s2Page`），否则会撞名，整部片打不开。需要新的画具写在自己的文件里，不改 `kit.js`；觉得画具有缺陷，写进汇报。

## 坐标、时间

- 逻辑画面 1920×1080（`W`、`H`、`CX`、`CY`），出片时整体放大到 3840×2160。`fn(c, tau, i)`：`tau` 是本段内的秒数，`i` 是 12fps 网格上的帧号。
- 镜头：`setView({ x, y, zoom, rot })` 或 `setView(null)`，然后画背景 `paperBg(c)` / `inkBg(c)`，之后画的东西都在镜头坐标里。
- 手绘的动作取 `twos(tau)`（一拍两帧），镜头运动用连续的 `tau`。线条、墨块的 seed 加上 `tick(tau)`，边缘每秒抖 8 次。
- 外圈的粗黑画框由 `film.js` 每帧最后画，段文件不用管，也别在框下 18 单位宽的边上放重要内容。

## 画风规则（样板是 `scenes/1-sanyan.js`，先看它）

- 参考视频抽帧：`out/ref/vsheet0.jpg`、`vsheet1.jpg`、`vsheet2.jpg`，原片 `/Users/fish2lab/Downloads/x_2102495989194236158.mp4`。样板抽帧 `out/anim/sanyan-check.jpg`。
- **颜色。** 只用 `K.paper` 纸、`K.ink` 墨、`K.g1..g3` 灰，加本段自己那一种压暗的颜色（`K.rose`、`K.plum`、`K.teal`/`K.ochre`、`K.vermil`、`K.stamp`）。不用渐变、不发光、不用高饱和色。实拍素材（制品照片、头像）按原样放。
- **形状。** 实心形状用 `block(c, 点, 颜色, { amp, spike, streaks })`，边缘是木刻刀口的毛边。线用 `stroke(c, 点, { w, p, dry })`；黑底上的白线用 `scratch()`；描一圈用 `outline()`。不用 `c.fillRect` 画可见的形状（除了铺满的底色）。
- **底纹。** `paperBg(c, 色, { extra: 'lines' | 'dots' })`、`inkBg(c)` 已带底纹。局部加底纹用 `texture(c, path, 'paper' | 'ink' | 'lines' | 'dots', 浓度)`。明暗起伏压在 5% 以内。
- **字。** 叙述、对白用手写楷体 `zh(c, 字, x, y, { size, p, color, align, weight })`，进度用 `writeP(tau, 开始时间, 字, 每字秒数)`。要读清的正文（价格、笑话）用印刷体 `printText(c, 字, x, y, { size, font: 'NSans', weight })`，折行用 `wrapText()`。主文案字号不小于 48，停留时间不少于「字数 × 0.12 秒 + 1.5 秒」。
- **展签字幕。** `caption(c, 字, tau, 出现时间, { t1: 收起时间 })`：左上角白底黑框，手写字逐字打出。每段开头用它写本段的名字或一句旁白，字要短（12 字以内）。
- **觉之瞳。** 墨块 + `eyeLines(c, x, y, r, { lid, open })`：只有眼皮线和睫毛，没有眉毛；伸出去的线只有一根。
- **人物。** 需要人物时画成木刻剪影：黑色实心块 + 几道白色刮痕线表现轮廓和标志物（灵梦的大蝴蝶结、紫的帽子和阳伞、觉的第三只眼、恋的帽子和闭着的眼），不画 Q 版大头、不画五官细节，不能像儿童画。
- **动。** 诙谐电影的节奏：停住、突然动、再停住。转场干脆，不用淡入淡出糊过去（交接画面除外）。

## 段与段怎么交接

相邻两段用同一张静止画面交接：前一段最后至少 0.1 秒、后一段最前至少 0.1 秒都只调用同一个交接函数。

| 交接 | 画面 | 前一段怎么收 | 后一段怎么起 |
|---|---|---|---|
| 1→2 | `handoffSukima` | 紧闭的眼皮线拉成隙间，裂开到满屏 | 从这张纸上排出版面 |
| 2→3 | `handoffBlack` | 深色页暗下去 | 黑暗里亮起烧瓶 |
| 3→4 | `handoffStream` | 魔药倒出来，流成横贯画面的小溪线 | 从这条线展开成水墨小溪 |
| 4→5 | `handoffBlack` | 自定 | 自定 |
| 5→6 | 第二批定 | | |
| 6→7 | `handoffBlack` | 自定 | 自定 |
| 7→1 | `handoffBlack` | 片尾落款后黑场 | 第 1 段直接切进桌面（已做好） |

## 素材（`photos.js` 里的名字）

用 `c.drawImage(PHOTOS[名字].img, x, y, w, h)` 画，`PHOTOS[名字].w / .h` 是像素尺寸。

`sanyanInk` `sanyanColor` 三眼封面水墨版和彩色版 · `art1`…`art4` 隙间月影四幅微喷 · `orig1`…`orig4` 原作名画 · `qr` 隙间月影 QQ 群二维码 · `avatar` 隙间月影头像 · `vol1` `vol2` `vol3` 三张黑白摊宣 1358×1920 · `badgeYes` `badgeNo` 吧唧 · `bottle1` `bottle2` `bottle3` 雏祭漂流瓶头像 640×640 · `omg` 笑话摊宣 · `kv` 主视觉。4K 上显示时，素材在逻辑画面里的高不要超过原图像素高的一半，否则发软。

新素材先放 `assets/img/`，在 `animation/tools/make-photos.py` 的列表里加一行，再跑 `.venv/bin/python animation/tools/make-photos.py`。

## 验收命令

worktree 里先接上依赖：`ln -s /Users/fish2lab/Project/BX/node_modules node_modules && ln -s /Users/fish2lab/Project/BX/.venv .venv`。在仓库根目录运行，退出码 0 且没有报错输出才算过：

```sh
node animation/tools/frames.mjs --q scene=<key> --grid 36 --cell 320          # 本段联系表 → out/anim/
node animation/tools/frames.mjs --q scene=<key> --frames 30,120,240 --w 3840   # 本段关键帧 4K 整帧
node animation/tools/frames.mjs --grid 30                                      # 全片能跑通
```

自己打开联系表和 4K 帧看：没有空白帧、没有截断的动作、字写完后停够时间、字在 4K 上清楚、首尾几帧和交接画面一致、颜色守规则。
