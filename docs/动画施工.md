每个段文件末尾调用一次 `scene({ order, key, name, dur, fn })` 登记自己，`film.js` 按 order 排成时间线。占位文件已登记好 order、key 和时长，替换 `fn` 即可。时长可以在 ±2 秒内调整，改了要在汇报里写。

所有脚本是经典脚本，共享一个全局作用域：**每个段文件里的顶层名字都要带本段前缀**（如 `S3`、`s3Flask`），否则会撞名，整部片打不开。局部变量也别叫 `S`、`W`、`H`、`K`、`M`，会遮住引擎和画具的全局名。需要新的画具就写在自己的文件里，不改 `kit.js`；觉得画具有缺陷，写进汇报。

**勤提交。** 上一批 agent 因为限流中断，没提交的活差点丢了。每做完一个镜头，或每次联系表看过没问题，就在自己的分支上提交一次，信息写 `wip: <段> <做到哪>`。最后一次提交写正式信息。

## 坐标、时间

- 逻辑画面 1920×1080（`W`、`H`、`CX`、`CY`），出片时整体放大到 3840×2160。`fn(c, tau, i)`：`tau` 是本段内的秒数，`i` 是 12fps 网格上的帧号。
- 镜头：`setView({ x, y, zoom, rot })` 或 `setView(null)`，然后画背景 `paperBg(c)` / `inkBg(c)`，之后画的东西都在镜头坐标里。
- 手绘的动作取 `twos(tau)`（一拍两帧），镜头运动用连续的 `tau`。线条、墨块的 seed 加上 `tick(tau)`，边缘每秒抖 8 次。
- 外圈的粗黑画框由 `film.js` 每帧最后画，段文件不用管，也别在框下 18 单位宽的边上放重要内容。

## 画风规则（样板是 `scenes/1-sanyan.js`，先看它）

- 参考视频抽帧：`out/ref/vsheet0.jpg`、`vsheet1.jpg`、`vsheet2.jpg`，原片 `/Users/fish2lab/Downloads/x_2102495989194236158.mp4`。样板抽帧 `out/anim/sanyan-check.jpg`。
- **颜色。** 只用 `K.paper` 纸、`K.ink` 墨、`K.g1..g3` 灰，加本段自己的压暗颜色：1 `K.rose`，2 `K.plum`，3 `K.teal`/`K.ochre`，4 `K.vermil`/`K.moss`（红绿和纸），6 `K.dot`（小红点），7 `K.stamp`。不用渐变、不发光、不用高饱和色。实拍素材（制品照片、头像）按原样放。
- **形状。** 实心形状用 `block(c, 点, 颜色, { amp, spike, streaks })`，边缘是木刻刀口的毛边。线用 `stroke(c, 点, { w, p, dry })`；黑底上的白线用 `scratch()`；描一圈用 `outline()`。不用 `c.fillRect` 画可见的形状（除了铺满的底色）。
- **底纹。** `paperBg(c, 色, { extra: 'lines' | 'dots' })`、`inkBg(c)` 已带底纹。局部加底纹用 `texture(c, path, 'paper' | 'ink' | 'lines' | 'dots', 浓度)`。明暗起伏压在 5% 以内。
- **字。** 屏上所有的字都用手写楷体 `zh(c, 字, x, y, { size, p, color, align, weight })`，进度用 `writeP(tau, 开始时间, 字, 每字秒数)`。价格、笑话正文这种要读清的字也用 `zh`，把 `tilt`、`jitter` 调到 .01 左右，字号放大；折行用 `wrapText(c, 字, 宽, 字号, ZH)`。不用 NSans、SMono 印刷体（用户 2026-09-23 要求全片手写）。主文案字号不小于 48，停留时间不少于「字数 × 0.12 秒 + 1.5 秒」。
- **展签字幕。** `caption(c, 字, tau, 出现时间, { t1: 收起时间 })`：左上角白底黑框，手写字逐字打出。每段开头用它写本段的名字或一句旁白，字要短（12 字以内）。
- **觉之瞳。** 墨块 + `eyeLines(c, x, y, r, { lid, open })`：只有眼皮线和睫毛，没有眉毛；伸出去的线只有一根。
- **人物。** 需要人物时画成木刻剪影：黑色实心块 + 几道白色刮痕线表现轮廓和标志物（灵梦的大蝴蝶结、紫的帽子和阳伞、觉的第三只眼、恋的帽子和闭着的眼），不画 Q 版大头、不画五官细节，不能像儿童画。
- **动。** 诙谐电影的节奏：停住、突然动、再停住。转场干脆，不用淡入淡出糊过去（交接画面除外）。

| `eyeLines` | 觉之瞳的眼皮线和睫毛 |
| `heartPts` `starPts` `capsule` `ellPts`（引擎） `rectPts`（引擎） | 常用形状的点 |

| `img(c, 名字, x, y, w, h, { fit: 'cover' \| 'contain', al })` | 画素材照片：铺满或装进框里，高质量缩放 |

| 引擎：`sm` `key` `keyPath` `arc` `settle` `spring` `easeOut…` `rng` `hash` `noise1` `lerp` `clamp` `mix` `alpha` | 时间曲线、随机数 |

## 段与段怎么交接

相邻两段用同一张静止画面交接：前一段最后至少 0.1 秒、后一段最前至少 0.1 秒都只调用同一个交接函数（定义在 `kit.js` 末尾），拼起来看不出接缝。

| 交接 | 画面 | 前一段怎么收 | 后一段怎么起 |
|---|---|---|---|
| 1→2 | `handoffSukima` | 紧闭的眼皮线拉成隙间，裂开到满屏 | 从这张纸上排出版面（已做好） |
| 2→3 | `handoffBlack` | 深色页暗下去（已做好） | 黑暗里一盏灯亮起，照出吧台 |
| 3→4 | `handoffStream` | 剩下的魔药倒出来，流成横贯画面的小溪线（`STREAM`，y≈640） | 小溪线拉直成一把尺子，放在手工桌上 |
| 4→5 | `handoffBlack` | 河流走远后干脆地暗下去 | 自定 |
| 5→6 | `handoffDot` | 黑底白字的「赢」缩成画面正中一个黑点（半径 `DOT_R`） | 这个黑点是一张黑点贴纸，镜头拉远露出表格 |
| 6→7 | `handoffBlack` | 自定 | 自定 |
| 7→1 | `handoffBlack` | 片尾落款后黑场 | 第 1 段直接切进桌面（已做好） |

## 素材（`photos.js` 里的名字）

用 `img(c, 名字, x, y, w, h, { fit })` 画，`PHOTOS[名字].w / .h` 是像素尺寸。

| 名字 | 是什么 | 像素 |
|---|---|---|
| `sanyanInk` `sanyanColor` | 三眼封面水墨版、彩色版 | 1408×1600 |
| `art1`…`art4`、`orig1`…`orig4`、`qr`、`avatar` | 隙间月影四幅微喷、原作、QQ 群二维码、头像 | — |
| `vol1` | 会赢的摊宣（黑白） | 1358×1920 |
| `vol3` | 帕秋莉的炼金工坊摊宣（黑白） | 1358×1920 |
| `hinaFlyer` | **新版**雏祭摊宣（黑白，替代旧的 `vol2`） | 1358×1920 |
| `board` | 东方二创红黑榜实体表（彩色海报） | 1697×2400 |
| `bottle1` `bottle2` `bottle3` | 雏祭漂流瓶里的三个头像。`bottle1` 是键山雏 fumo 布偶照片 | 640×640 |
| `badgeYes` `badgeNo` | 阿求 YES/NO 吧唧，可当奖品吧唧 | 666、684 |
| `omg` `kv` `vol2` | 旧笑话摊宣、主视觉、旧雏摊宣，不用 | — |

4K 上显示时，素材在逻辑画面里的高不要超过原图像素高的一半，否则发软。

新素材先放 `assets/img/`，在 `animation/tools/make-photos.py` 的列表里加一行，再跑 `.venv/bin/python animation/tools/make-photos.py`。

## 验收命令

worktree 里先接上依赖：`ln -s /Users/fish2lab/Project/BX/node_modules node_modules && ln -s /Users/fish2lab/Project/BX/.venv .venv`。在仓库根目录运行，退出码 0 且没有报错输出才算过：

```sh
node animation/tools/frames.mjs --q scene=<key> --grid 36 --cell 320          # 本段联系表 → out/anim/
node animation/tools/frames.mjs --q scene=<key> --frames 30,120,220 --w 3840   # 本段关键帧 4K 整帧（10 秒的段只有 0–239 帧）
node animation/tools/frames.mjs --grid 30                                      # 全片能跑通
```

自己打开联系表和 4K 帧看：没有空白帧、没有截断的动作、字写完后停够时间、字在 4K 上清楚、首尾几帧和交接画面一致、颜色守规则。
